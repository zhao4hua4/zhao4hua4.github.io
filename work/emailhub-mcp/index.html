EmailHub MCP

Email tools for AI assistants.

A self-hosted email workspace in Go, with bilingual search, a web interface and authenticated tools for AI assistants.

Open-source software · v0.1.0 preview

The contribution

EmailHub MCP brings several mailboxes into one workspace through a browser interface and Model Context Protocol (MCP) tools. Written in Go, it connects Microsoft Graph and IMAP/SMTP providers to a local mail store and search index, supporting search, drafts, replies and mailbox organisation.

Why it matters

Useful agent tools need clear account context and predictable actions. Search results retain their account and folder provenance; permission checks, saved draft revisions and recorded operation outcomes make email actions explicit and inspectable.

Implementation

The v0.1.0 preview includes bilingual text search, resumable indexing, revision-controlled drafts and mailbox organisation. The public test suite covers permissions, index recovery, interrupted sends and a 10,000-message synthetic search fixture. Release packages are available for Linux ARM64 and AMD64.

How it works

01

Sync with visible coverage

Provider adapters import mailbox history in resumable passes. Persisted folder inventories and continuation cursors keep progress visible while recent messages become searchable. Attachments are fetched only when a specific file is requested or used in an outgoing message.

02

Keep search rebuildable

SQLite stores mail, accounts, jobs and drafts. A derived Bleve index supports English and Chinese text search, filters and snapshot pagination. Versioned message updates allow interrupted index writes to replay and a missing index to rebuild from the database.

03

Make agent actions explicit

OAuth scopes and current account permissions gate MCP tools. Draft edits and sends refer to saved revisions. A durable operation ledger records requests before provider submission; an uncertain send outcome is retained for inspection without automatic resubmission.

Code & documentation

An initial preview for a single owner, with a documented Ubuntu 24.04 deployment. Search indexes message text and attachment filenames; attachment contents stay at the provider until requested. Provider-specific capabilities and release limits are documented in the repository.
