Prompt as Stratified Interface

Understand what an evaluation is measuring.

A layered account of how instructions, labels and answer mappings shape multilingual model evaluation.

ORACLE 2026 · Workshop Accepted

First author

Explore the researchPaper · Coming soon
OverviewFindingsMethodPublication & citationMaterials

The contribution

We study the prompt as a stratified interface. A Chinese–English natural-language-inference experiment separates instruction language, category names, arbitrary answer symbols and output requirements, making label-mediated effects explicit.

Why it matters

Model comparisons depend on how a task is presented. Separating the interface into controlled components gives evaluation teams a clearer basis for interpreting changes in multilingual performance.

What the evidence shows

The study identifies label presentation as a component of apparent prompt-language effects. Its contribution is a controlled way to analyse the interface through which multilingual model capability is measured.

How it works

01

Separate the layers

Distinguish the instruction language, semantic category vocabulary and symbols required in the model's response.

02

Control the mappings

Compare semantic labels, arbitrary A/B/C mappings and symbols paired with semantic anchors within the same inference task.

03

Interpret model-specific behaviour

Trace performance changes to interface choices and examine how their direction and magnitude vary across models.
