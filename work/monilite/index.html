MONILite. Research tooling in Python.

The contribution

MONILite offers a concrete engineering artifact alongside the research: a self-contained Linux monitoring application whose implementation separates collection, persistent history, HTTP serving and the command-line entry point.

Why it matters

Readable interfaces and inspectable implementations make tools easier to adopt in research workflows. MONILite connects system metrics to persistent history and a usable dashboard in a small application.

Implementation

The public repository includes the implementation, installation instructions and architecture documentation.

How it works

01

Collect

A Python collector gathers CPU, memory, disk and GPU metrics from a Linux host.

02

Store

SQLite provides persistent metric history within the application.

03

Inspect

A bundled Flask dashboard and JSON API expose the recorded metrics.
