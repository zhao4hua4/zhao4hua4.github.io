CiteVault

From a claim to its source.

A self-hosted research library for checking human and AI writing against original papers, with traceable citations and access to specific pages.

Open-source software · v1.0.1

The contribution

CiteVault brings original papers, citation exports and source retrieval into one research workflow. A browser portal supports a shared reading library, while authenticated Model Context Protocol (MCP) tools let a connected AI retrieve original files, page text and rendered pages. Each check can identify the exact document and physical pages used as evidence.

Why it matters

Checking a literature review or AI answer requires returning to the evidence behind each claim. CiteVault keeps source identity, document versions and reading coverage visible, helping reviewers inspect quotations, tables, figures and the scope of reported findings.

Implementation

Version 1.0.1 includes a browser portal, individual member access, citation conversion, versioned BibTeX, REST uploads and read-only MCP retrieval. Tests cover physical-page identity, rendered images, source-byte preservation and bounded PDF search. The release passed Linux and macOS test and packaging jobs, plus a Docker build and startup check.

How it works

01

Preserve originals and provenance

Original PDFs and citation exports retain their bytes and SHA-256 hashes. Local citation conversion produces usable BibTeX, while revision records preserve links to the original citation file and contribution history.

02

Retrieve the pages that matter

Read-only MCP tools provide catalog search, bibliography retrieval, original downloads, physical-page text and page images. PDF.js supplies text extraction and rendering, so a reader can inspect figures, tables and surrounding context from the original document.

03

Review claims with explicit coverage

The documented workflow separates a draft into checkable claims, identifies the intended sources and records the files and pages inspected. A researcher or connected AI assesses support and proposes corrections, with missing sources and unresolved claims kept visible for human review.

Code & documentation

A self-hosted Node.js application for an individual or a shared research collection. SQLite stores records and provenance; PDF.js handles document reading. The workflow uses papers supplied to that library, with findings tied to the material actually inspected.

Project source is available under the MIT licence. The repository includes installation instructions, a source release and a guide to checking writing against original papers.
